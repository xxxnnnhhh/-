# 剧场整合 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将圆桌与故事机器整合为「剧场」，新增世界系统、角色卡增强（五维/能力/装备/类型）、Skills 写作风格挂载、战斗比重调节、AI 预读取与幕后聊天。

**Architecture:** 后端新增 `src/theater/`（世界模型、剧场会话、战斗判定、预读取），扩展 `src/characters/models.py`（角色卡字段）；前端新增 `TheaterPage`（三栏：控制台/演出区/角色卡）+ 幕后聊天浮窗，替代圆桌与故事机器入口。讨论模式复用 `src/roundtable/`，演绎模式复用 `src/story/`。

**Tech Stack:** FastAPI, Python dataclasses, React (Vite), WebSocket, 现有 SkillManager / 三我情绪算法。

## 验收标准

- 导航只有「剧场」一个入口，圆桌/故事机器功能均可通过模式切换使用。
- 角色卡可配置类型/五维/能力/装备，旧角色兼容。
- 世界可创建/编辑，世界观注入演出。
- Skills 可挂到角色/世界并影响输出风格。
- 战斗场景有比重滑块（文字↔数值），判定含属性/装备/情绪修正。
- 开演前必须完成 AI 预读取并生成共识摘要。
- 幕后聊天可用。
