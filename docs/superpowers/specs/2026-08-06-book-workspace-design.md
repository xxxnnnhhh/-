# 作品工作台（静态版）设计

日期：2026-08-06

## 目标

把散落的「小说管线 / 剧场 / 人物库 / 工作流」收进"一本书"的容器：

- 新增「书架」页签（取代原「小说管线」页签）
- 进书后是作品工作台，7 个分页：总览 / 世界观 / 角色 / 大纲章节 / 演绎 / 流水线 / 工作流
- 第一迭代只做**静态关联**：书里能看到角色、演绎记录、章节、世界观；不做"演绎→素材→成书"动态闭环

## 信息架构

```
书架（作品卡片列表 + 新建作品）
  └─ 作品工作台
       总览     —— 书名/创意/进度/最近演绎/最近章节/存储路径
       世界观   —— 读流水线产出 meta/world_foundation.md，6 维展示（只读）
       角色     —— 关联的人物库角色卡（三我/五维/装备/技能），可增删
       大纲章节 —— 卷纲/近纲摘要 + 章节状态列表 + 章节正文查看
       演绎     —— 关联的剧场会话列表 + 新开演绎（建会话并挂到书下）
       流水线   —— 原小说管线视图（连跑/断点续跑/停止/完整文本）
       工作流   —— 7 个子工作流的跳转入口（高级模式）
```

## 数据模型（后端）

`NovelProject` 扩展四个字段（向后兼容）：

- `world_id: str` —— 关联的剧场世界（建书时自动创建一个空 World）
- `character_ids: list[str]` —— 关联人物库角色
- `theater_session_ids: list[str]` —— 关联剧场会话
- 章节索引：不落盘，运行时扫描 `workspace/story/*/chapter.md` 生成

## API（新增，均在 `/api/novel/pipelines` 下）

- `GET /{project_id}/content` —— 聚合：作品信息 + 世界 + 角色列表 + 大纲摘要 + 章节列表 + 演绎会话
- `POST /{project_id}/characters`（body: character_id）—— 关联角色
- `DELETE /{project_id}/characters/{character_id}` —— 取消关联
- `POST /{project_id}/theater`（body: title/scene/mode）—— 创建并关联剧场会话
- `GET /{project_id}/chapters/{chapter}/text` —— 章节正文

## 数据流（静态版）

- 建书 → 自动建一个同名空 World 并挂到作品（`world_id`）
- 角色分页「从人物库添加」→ 写入 `character_ids`
- 演绎分页「新开演绎」→ 用本书角色 + 世界创建 TheaterSession → 写入 `theater_session_ids`
- 流水线跑完 → 章节列表自动出现（扫描 story/ 目录）

## 不做（下一迭代）

- 演绎日志 → 章节素材提炼 → 注入大纲导演
- 正文编辑 / 历史版本 / Agent 改写
- 世界观双击编辑
- 成本预估 / 巡航会话化

## 验证

- 建书后工作台 7 分页可打开，世界观/角色/章节/演绎为空态友好
- 关联角色、新开演绎、章节查看 API 返回正确
- 流水线连跑功能不回归
